# Getting Started

## Find your way around

| Destination | Purpose |
|---|---|
| **Library** | Permanent catalog, console browsing, filters, findings, and selected-file actions |
| **Add games** | Uploads, network-share imports, transfer progress, and import history |
| **Activity** | Processing jobs, progress, errors, and available retry/detail tools |
| **Settings** | Verification defaults, connections, server information, and update checks |

Imports are sessions within one Library, not separate libraries. Advanced mode
reveals server tools, detailed results, move previews, recovery, and raw evidence.
It is a browser presentation preference, not a security or policy switch.

## Your first collection

1. Back up a small folder of test ROMs.
2. In **Add games**, choose a folder upload and wait for transfer/preparation.
3. Open **Library** and browse the detected console. Detection is provisional,
   not proof of verification.
4. Select files and choose **Check selected**. Review the dialog and choose
   check-only or explicitly approved organization where offered.
5. Acknowledge any enabled online fingerprint/metadata lookups before starting.
6. Watch the operation in **Activity** and inspect the resulting file findings.
7. Resolve errors and review held files; a completed job does not mean every file
   is eligible for organization or publication.

## Browse and select precisely

Search, console filters, status filters, sorting, and open file details are
bookmarkable. Browser Back/Forward works with those views.
Cover/list mode, saved views, theme, and Advanced mode are local browser preferences.

Actions target explicit files, not a title inferred from a filename.
**Select all filtered** spans matching pages; **Check entire library** ignores the
current filters. Selecting a supported disc/companion member expands to its linked
group. Review the operation scope before confirming.

See [Verification and Organization](Verification-and-Organization.md) to interpret
findings and [Imports and Storage](Imports-and-Storage.md) for transfer behavior.
